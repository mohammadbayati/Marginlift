# نقشه راه ۳۰روزه اعتبارسنجی MarginLift

هدف ۳۰ روز آینده ساختن شواهد واقعی است، نه اضافه‌کردن فیچرهای زیاد.

## معیار موفقیت ماه اول

- ۲۰ outreach دستی.
- ۵ جلسه discovery.
- ۲ مشتری حاضر به data-share.
- ۱ live holdout یا paid diagnostic.
- ۱ LOI یا تعهد شفاهی برای ادامه.

## هفته ۱: Outreach و discovery

| روز | کار | خروجی |
| --- | --- | --- |
| ۱ | انتخاب ۱۰ حساب اول از CRM | لیست اولویت‌دار |
| ۲ | شخصی‌سازی پیام‌ها | ۱۰ پیام آماده |
| ۳ | ارسال ۵ پیام | ثبت وضعیت |
| ۴ | ارسال ۵ پیام بعدی | ثبت وضعیت |
| ۵ | درخواست معرفی گرم | ۲ مسیر معرفی |
| ۶ | آماده‌سازی دمو برای هر vertical | talk track اختصاصی |
| ۷ | جمع‌بندی پاسخ‌ها | اصلاح ICP |

## هفته ۲: Data-share و diagnostic

| کار | خروجی |
| --- | --- |
| اجرای ۳ discovery call | qualification score |
| ارسال pilot data request | CSV یا تعهد ارسال داده |
| ساخت گزارش نمونه با داده دمو | نسخه قابل‌ارسال |
| مذاکره paid diagnostic | scope و قیمت |

## هفته ۳: پایلوت اول

| کار | خروجی |
| --- | --- |
| دریافت داده aggregate | data quality report |
| تحلیل تاریخی | uplift و waste estimate |
| ساخت policy پیشنهادی | next campaign plan |
| جلسه readout | go/no-go live holdout |

## هفته ۴: بستن proof

| کار | خروجی |
| --- | --- |
| طراحی live holdout | experiment brief امضا‌شدنی |
| مذاکره قرارداد یا LOI | تعهد ادامه |
| به‌روزرسانی deck با یادگیری واقعی | investor-ready proof |
| تصمیم production roadmap | ۳ فیچر بعدی |

## تصمیم‌های سخت

- اگر ۵ discovery پشت‌سرهم گفتند کنترل‌گروه ندارند، محصول باید «holdout setup» را به‌عنوان feature اولویت‌دارتر کند.
- اگر مشتری‌ها داده aggregate هم نمی‌دهند، باید از free calculator/benchmark برای lead qualification استفاده شود.
- اگر صرفه‌جویی تخمینی کمتر از قیمت ماهانه است، ICP باید به حساب‌های بزرگ‌تر یا دسته پرتخفیف‌تر منتقل شود.
