# ارزیابی APIهای عمومی برای MarginLift

منبع بررسی: مخزن [public-apis/public-apis](https://github.com/public-apis/public-apis)

## تصمیم فعلی

در نسخه MVP، هیچ API عمومی در مسیر اصلی تحلیل استفاده نمی‌شود.

دلیل: ارزش اصلی MarginLift از داده اختصاصی مشتری می‌آید؛ یعنی تاریخچه کمپین، گروه کنترل، سفارش، هزینه مشوق و رفتار خرید. API عمومی نمی‌تواند جای این داده را بگیرد.

## APIهای بالقوه برای فازهای بعدی

### ۱. Enrichment برای فروش B2B

در بخش Business، APIهایی مثل Clearbit Logo، ORB Intelligence، Tomba و Signaliz برای company lookup، email finder و lead enrichment آمده‌اند. کاربرد احتمالی برای MarginLift:

- ساخت CRM سبک برای لیست مشتریان هدف
- غنی‌سازی دامنه شرکت‌ها
- پیدا کردن ایمیل کاری مدیر رشد یا مارکتینگ
- نمایش لوگوی شرکت در workspace مشتری

این‌ها برای GTM مفیدند، نه برای موتور تحلیل.

### ۲. Calendar و holiday enrichment

در بخش Calendar، APIهایی مثل Nager.Date و The Calendar برای تعطیلات عمومی آمده‌اند. کاربرد احتمالی:

- علامت‌گذاری روزهای تعطیل یا مناسبت‌ها در گزارش کمپین
- جلوگیری از تفسیر اشتباه uplift در روزهای خاص
- توضیح بهتر افت‌وخیز رفتار خرید

برای بازار ایران باید جداگانه بررسی شود که پوشش تقویم ایران دقیق و قابل‌اعتماد باشد.

### ۳. Currency exchange

در بخش Currency Exchange، APIهایی مثل Currency-api، Frankfurter و Exchangerate.host دیده می‌شوند. کاربرد احتمالی:

- تبدیل ارز برای مشتری‌های چندکشوری
- normalize کردن revenue در گزارش‌های منطقه‌ای

برای بازار ایران، نرخ رسمی و نرخ بازار ممکن است اختلاف جدی داشته باشند؛ بنابراین استفاده کورکورانه از این APIها می‌تواند گزارش را گمراه کند.

### ۴. BI و خروجی سازمانی

در بخش Open Source Projects، Metabase به‌عنوان BI server آمده است. کاربرد احتمالی:

- اتصال خروجی MarginLift به داشبورد داخلی مشتری
- ساخت report برای تیم مالی یا رشد

این مورد برای فاز enterprise جذاب است، اما برای MVP فعلی ضروری نیست.

## اولویت پیشنهادی

1. اولویت فوری: هیچ API خارجی.
2. فاز پایلوت: فقط import CSV و تحلیل داخلی.
3. فاز فروش و GTM: بررسی Tomba، Signaliz یا Clearbit برای lead enrichment.
4. فاز محصول پیشرفته: calendar enrichment برای توضیح اثر تعطیلات و مناسبت‌ها.
5. فاز enterprise: integration با BI مثل Metabase.

## اصل تصمیم

هر API خارجی باید یکی از این دو کار را انجام دهد:

- دقت تصمیم مشوق را بهتر کند.
- فروش یا onboarding مشتری را سریع‌تر کند.

اگر هیچ‌کدام را انجام ندهد، نباید وارد محصول شود.
