## چک‌لیست قبل از ارسال

- هر پیام فقط یک سؤال داشته باشد.
- از ادعای نتیجه واقعی برای مشتری استفاده نشود.
- پیام با مسئله مخاطب شروع شود، نه معرفی محصول.
- ایمیل plain text باشد.
- برای outreach سرد، دامنه ارسال جداگانه، SPF، DKIM و DMARC آماده باشد.
- پاسخ unsubscribe یا «دیگر پیام ندهید» همان روز ثبت شود.
