- شناسه شرکت‌کننده:
- نقش سازمانی:
- صنعت و اندازه سازمان:
- تاریخ و مدت جلسه:
- دستگاه و مرورگر:
- روش تعامل: ماوس / کیبورد / فناوری کمکی
- screen reader و نسخه: Narrator / NVDA / استفاده نشد

- رضایت برای ضبط: بله / خیر
