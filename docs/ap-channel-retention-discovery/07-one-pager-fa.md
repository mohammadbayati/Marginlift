# MarginLift برای خرید مجدد بسته اینترنت در آپ

## تصمیم بهتر، پیش از خروج کاربر از چرخه خرید

MarginLift کمک می‌کند مشخص شود کدام خریدار بسته اینترنت در معرض خارج‌شدن از چرخه خرید آپ است، چه زمانی باید با او ارتباط گرفت، آیا واقعاً قابل‌بازگشت است و تا چه سقف هزینه‌ای مداخله توجیه دارد.

## مسئله

یک rule ثابت برای همه کاربران تفاوت بسته روزانه و ماهانه، اپراتور، فاصله خرید، ارزش مالی و واکنش به مشوق را نادیده می‌گیرد. در نتیجه ممکن است:

- مداخله زمانی انجام شود که دیر شده است.
- کاربرانی که طبیعی خرید می‌کنند مشوق غیرضروری بگیرند.
- برای کاربران غیرقابل‌بازگشت بودجه مصرف شود.
- افزایش conversion با افزایش سود اشتباه گرفته شود.

## رویکرد MarginLift

```text
موعد خرید بعدی
  -> احتمال خروج از چرخه آپ
  -> قابلیت بازگشت
  -> ارزش و هزینه مداخله
  -> Action / No Action
  -> Holdout و نتیجه مالی
```

مدل، کاربر را در وضعیت‌های `Active`، `Due`، `Lapsed`، `Dormant` و `Reactivated` دنبال می‌کند و احتمال خریدنکردن در پنجره‌های ۳۰، ۹۰ و ۱۸۰ روزه را با رویکرد survival برآورد می‌کند.

## چیزی که آپ دریافت می‌کند

- خط پایه خرید مجدد و cohortهای اصلی.
- تعریف پویا و قابل ممیزی از ریزش کانالی.
- audience اولویت‌بندی‌شده با reason code.
- پیشنهاد زمان اقدام و سقف هزینه.
- گزینه واقعی `no_action`.
- طرح holdout با metric و guardrail از پیش ثبت‌شده.
- گزارش مدیریتی Scale، Iterate یا Stop.

## مرز ادعا

MarginLift با داده داخلی آپ درباره خرید از رقبا ادعا نمی‌کند. پیش از live holdout، خروجی فقط برآورد تاریخی است. فقط نتیجه آزمایش سالم به‌عنوان اثر افزایشی تأییدشده گزارش می‌شود.

## شروع کم‌ریسک

قدم نخست یک اتصال فنی یا انتقال گسترده داده نیست. تیم آپ فقط schema و ۱۰۰ ردیف کاملاً ناشناس ارائه می‌دهد. MarginLift آمادگی داده را ارزیابی و تصمیم `Proceed / Fix Data / Stop` صادر می‌کند.

## معیار موفقیت

هدف، کاهش ظاهری churn نیست؛ هدف **افزایش سود مشارکتی خرید مجدد به‌ازای هر کاربر واجد شرایط، همراه با کاهش نرخ Dormant و حفظ guardrailهای درآمد و تجربه مشتری** است.
