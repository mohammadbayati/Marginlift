# درخواست داده پایلوت MarginLift

این فایل برای ارسال به تیم داده/BI مشتری است. هدف این است که پایلوت بدون اتصال به محیط عملیاتی شروع شود و هیچ داده شخصی لازم نباشد.

## حداقل فایل موردنیاز

یک CSV aggregate یا anonymized از ۱ تا ۳ کمپین اخیر کافی است.

| ستون | الزامی | توضیح |
| --- | --- | --- |
| campaign_id | بله | شناسه کمپین |
| segment | بله | نام سگمنت یا rule سگمنت |
| treatment | بله | کنترل، فقط پیام، تخفیف کوچک، مشوق قوی |
| users | بله | تعداد کاربران در گروه |
| conversions | بله | تعداد خرید/فعال‌سازی در پنجره سنجش |
| revenue | بله | GMV یا درآمد گزارش‌شده |
| incentive_cost | بله | هزینه کل مشوق برای همان گروه |
| gross_margin_rate | بله | حاشیه سود ناخالص به‌صورت ۰.۳۲ یا ۳۲ |
| baseline_policy | بهتر است | سیاست پایه‌ای که قرار است پیشنهاد جدید با آن مقایسه شود؛ مثل `high_incentive` |
| channel | بهتر است | پوش، پیامک، ایمیل، in-app |
| channel_cost_per_user_toman | بهتر است | هزینه ارسال پیام/کانال به‌ازای هر کاربر |
| fulfillment_subsidy_per_user_toman | بهتر است | هزینه ارسال رایگان یا سابسیدی غیر از تخفیف مستقیم |
| measurement_window_days | بهتر است | مثلا ۷ روز |
| control_group_flag | بهتر است | اگر treatment خودش کنترل نیست |

## چیزهایی که نمی‌خواهیم

- نام، شماره موبایل، ایمیل یا آدرس مشتری.
- شماره کارت، داده پرداخت، شناسه دستگاه یا داده حساس.
- داده خام کاربر، مگر اینکه کاملا hash/anonymize شده باشد و مشتری خودش اجازه بدهد.

## کیفیت داده

قبل از شروع، این موارد باید روشن شوند:

- آیا کنترل‌گروه یا holdout وجود داشته است؟
- کاربران بین گروه‌ها هم‌پوشانی دارند یا نه؟
- نرخ تبدیل بر اساس سفارش است یا کاربر یکتا؟
- درآمد، GMV است یا revenue خالص؟
- هزینه مشوق شامل cashback/ارسال رایگان/تخفیف تامین‌کننده هست یا فقط تخفیف مستقیم؟

## خروجی مورد انتظار از مشتری

فایل CSV با یک ردیف برای هر ترکیب campaign + segment + treatment.

نمونه:

```csv
campaign_id,segment,treatment,users,conversions,revenue,incentive_cost,gross_margin_rate,baseline_policy,channel,channel_cost_per_user_toman,measurement_window_days

RET-001,کاربران وفادار اخیر,small_discount,3100,272,602000000,77500000,0.32,high_incentive,push,1800,7
```
