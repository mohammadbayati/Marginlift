# DigiPay data request

## Diagnostic required

- `customer_id_hash`
- product/use-case identifier
- cohort and eligibility signal
- historical action/treatment where available
- outcome status/timestamp
- revenue/value field
- available incentive, message and channel cost fields

## Pilot required

- assignment and treatment/control label
- assignment timestamp
- exposure timestamp
- delivery status/timestamp
- outcome timestamp/status
- exclusions, consent and contact-cap fields where applicable
- data snapshot identifier and lineage metadata

## Optional enrichment

- risk restriction signal (DigiPay remains authority)
- product metadata
- historical experiment assignment
- channel and campaign identifiers

No raw name, national ID, card number or mobile number is required for the initial diagnostic. Batch delivery is acceptable. CRM/Growth, Data, Finance, Outcome and Risk/Security owners are required as applicable.
