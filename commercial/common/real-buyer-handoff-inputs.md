# REAL_BUYER_HANDOFF_INPUTS

Required before a real Diagnostic begins:

- buyer identity and legal/procurement contact
- use case and one-cohort scope
- owners: CRM/Growth, Data, Finance, Outcome, Security as applicable
- target KPI and outcome definition/window
- current policy and control feasibility
- data availability, snapshot and transfer path
- FinancialProvenance owner/formula path
- security/deployment review path
- commercial scope, currency and payment decision
- external acceptance of SOW/quote

These are real-buyer inputs, not synthetic defaults.
