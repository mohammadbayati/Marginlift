# Qualification gate

`QUALIFIED` requires a meaningful intervention decision, measurable target outcome, plausible volume/history, control/holdout feasibility, CRM/Growth and Data owners, Finance involvement, accessible event/action/outcome data, and willingness to measure rather than demand a guarantee.

`QUALIFIED_WITH_CAVEATS` means the decision is real but one or more fields are `BUYER_CONFIRMATION_REQUIRED`.

`NOT_QUALIFIED` means no measurable decision, no meaningful intervention, no safe data path or unwillingness to preserve valid measurement.

No arbitrary volume threshold is imposed before buyer data is reviewed.
