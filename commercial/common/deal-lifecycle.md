# First Diagnostic deal lifecycle

| Stage | Entry / required artifacts | Buyer action | MarginLift action | Exit / blocker |
|---|---|---|---|---|
| LEAD | Problem signal | Share context | Triage fit | QUALIFIED or NOT_QUALIFIED |
| QUALIFIED | Outcome, owner and intervention hypothesis | Confirm discovery | Run qualification gate | QUALIFIED_WITH_CAVEATS or SCOPING |
| SCOPING | Discovery notes | Attend workshop; define scope | Draft summary and data request | DIAGNOSTIC_PROPOSED |
| DIAGNOSTIC_PROPOSED | Offer/SOW/quote draft | Review scope and terms | Answer questions | COMMERCIAL_REVIEW |
| COMMERCIAL_REVIEW | Procurement/security questions | Approve externally | Resolve artifacts | DIAGNOSTIC_ACCEPTED or CLOSED |
| DIAGNOSTIC_ACCEPTED | External acceptance; owners identified | Provide data path | Schedule kickoff | DATA_INTAKE |
| DATA_INTAKE | Data request and transfer placeholder | Supply safe sample | Validate schema/PII | DIAGNOSTIC_IN_PROGRESS or DATA_BLOCKED |
| DIAGNOSTIC_IN_PROGRESS | Validated data | Answer unresolved definitions | Run canonical readiness/analysis | FINANCE_INPUT_REQUIRED, METRIC_CONTRACT_REVIEW or EVIDENCE_PACKAGE_READY |
| DIAGNOSTIC_REVIEW | Evidence Package | Review findings | Present package | COMPLETE, NO_GO or PILOT_PROPOSED |
| PILOT_PROPOSED | Pilot entry gate passes | Separately accept Pilot | Prepare frozen contract | Pilot workflow begins externally |
| NO_GO / CLOSED | Blocker or completed decision | Resolve or archive | Preserve audit record | Re-open only with new scope |

Buyer-dependent values are never inferred. Status is process tracking, not evidence authority.
