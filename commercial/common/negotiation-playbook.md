# MarginLift negotiation playbook

| Buyer concern | Response | Boundary | Concession | Do not concede |
|---|---|---|---|---|
| “We only pay if uplift is positive.” | The Diagnostic/Pilot buys valid measurement and a decision, not a guaranteed outcome. | No guaranteed uplift/profit. | Diagnostic credit toward pilot. | Contingent-only payment for positive results. |
| “We can do this in BI.” | BI reports what happened; MarginLift structures policy comparison and integrity evidence. | No CRM/BI replacement claim. | Provide a narrow export and evidence schema. | Claiming BI is incapable. |
| “Our CRM already personalizes.” | Personalization chooses actions; the holdout tests whether they changed economics. | CRM remains execution owner. | Start with one product/cohort. | Automatic execution promise. |
| “Can you run campaigns?” | MarginLift provides policy assignments and evidence; buyer CRM executes. | Execution is buyer-owned. | Support mapping and logging design. | Taking campaign credentials. |
| “We need VPC.” | Topology is evaluated during security/deployment review. | No turnkey VPC promise. | Scope a technical review. | Promising deployment before review. |
| “Why pay for Diagnostic?” | It identifies data gaps and can safely conclude that a pilot is not justified. | No free pilot by default. | Fixed scope and explicit deliverables. | Hiding unresolved data gaps. |
| “Give us a free pilot.” | A controlled pilot requires expert design, integrity monitoring and finance reconciliation. | Paid work starts after scope approval. | Small paid Diagnostic first. | Unpaid production execution. |
| “Your price is too high.” | Reduce scope, not truth controls: one cohort, one KPI, one package. | Integrity and provenance stay in scope. | Remove optional enrichment. | Removing holdout or finance review. |
| “Can we add another cohort?” | Yes, as a documented scope change after impact review. | New cohort changes design and price. | Quote an additive adjuster. | Silent scope expansion. |
| “Can you guarantee ROI?” | No. We can define the formula, controls and evidence required to evaluate ROI. | No guarantee. | Make acceptance criteria concrete. | Unsupported ROI claim. |
