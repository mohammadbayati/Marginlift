# Diagnostic kickoff checklist

Before start: scope confirmed; use case confirmed; owners identified; data path agreed; external commercial acceptance confirmed; Metric Contract draft initiated; Finance inputs requested; security requirements known; timeline agreed.

Kickoff agenda: objectives, scope, roles, data transfer, privacy boundary, validation gates, open decisions, communication cadence, acceptance criteria and next meeting.

Decision log fields: date, decision, owner, evidence/reference, unresolved consequence and next action.
