# Pilot entry decision

`PilotEntryDecision` is ready only when Diagnostic is complete; use case remains valid; Metric Contract can be frozen; owners are present; control/holdout is feasible; data is ready; Finance formula exists; execution logging is feasible; security path is acceptable; and Pilot terms are separately agreed externally.

States: `READY_FOR_PILOT_PROPOSAL`, `READY_FOR_PILOT_AFTER_INPUTS`, `NOT_READY_FOR_PILOT`, `NO_GO`.

Diagnostic completion never auto-authorizes a Pilot.
