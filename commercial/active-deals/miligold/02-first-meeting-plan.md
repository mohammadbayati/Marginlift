# MilliGold first meeting (30 minutes)

**Objective:** confirm the first-purchase → second-purchase question and secure a 60-minute scoping workshop.

| Time | Question | Why | Good signal / warning | Follow-up |
|---|---|---|---|---|
| 0–5 | What second-purchase decision is currently uncertain? | Establishes value | Specific intervention decision / generic retention goal | Narrow scope |
| 5–8 | How is a first purchase recorded and dated? | Defines index event | Stable event ID/timestamp / ambiguous sequence | Request event dictionary |
| 8–11 | What counts as a second purchase? | Prevents outcome drift | Explicit event rule / blended repeat behavior | Finance/Data review |
| 11–14 | What outcome window would change action? | Window is buyer-owned | Business rationale / arbitrary example only | Mark confirmation required |
| 14–17 | Who receives intervention versus no action today? | Maps policy | CRM rules / no control | Draft policy map |
| 17–20 | Can one cohort preserve a holdout? | Causal feasibility | Yes / cannot isolate contacts | Re-scope if needed |
| 20–23 | Which contribution-margin and cost inputs are approved? | Financial provenance | Finance owner/formula / revenue-only view | Finance checklist |
| 23–25 | What data exists for purchase, action, delivery and outcome? | Intake feasibility | Hashed batch possible / missing history | Safe schema review |
| 25–27 | Who owns Marketing/CRM, Data, Finance and outcome? | Execution clarity | Named owners / no accountable owner | Nominate participants |
| 27–29 | What security and transfer path is acceptable? | Safe intake | Batch review / immediate VPC demand | Security follow-up |
| 29–30 | Will you join scoping and share schema-level information? | Concrete next step | Date/owners proposed / indefinite interest | Send follow-up |

Repeat-purchase continuity is not part of the initial offer. Reference `commercial/miligold/first-meeting-kit.md`.
