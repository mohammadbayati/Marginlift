# DigiPay procurement and security fast path

## Answer now

MarginLift supports hashed identifiers and batch-first workflows; the buyer retains CRM execution. Initial Diagnostic does not require raw PII where the configured use case permits it. Evidence is lineage-aware and strong claims remain fail-closed.

## Requires review

Data transfer method, retention terms, deployment topology, access controls, legal terms, and any buyer VPC requirement must be reviewed with the buyer’s Security/Legal teams.

## Not currently promised

Turnkey VPC deployment, enterprise multi-tenancy, certifications, SLA, or automatic real-time CRM execution. The deployment architecture is agreed during security review and is outside the default Diagnostic scope.

## Procurement checklist

Confirm purchased stage (Diagnostic), deliverables, duration assumptions, payment milestones, acceptance criteria, exclusions, owners, change control and post-Diagnostic decision gate. Acceptance is based on valid deliverables, not positive uplift.
