Sprint 4 / PostgreSQL Migration

ارتقای سرور MarginLift بدون از دست‌دادن داده

در نسخه جدید، PostgreSQL منبع اصلی داده است و CSVهای خام فقط به‌صورت رمزنگاری‌شده ذخیره می‌شوند. قبل از deploy، سه secret جدید را در فایل .env قرار دهید.

۱. نسخه پشتیبان

cd /opt/marginlift
cp .env /root/marginlift.env.backup
cp data/db.json /root/marginlift-before-postgres.json

۲. تولید secretها

این دستور را سه بار اجرا کنید و هر خروجی را جدا نگه دارید:

openssl rand -hex 32

۳. تکمیل فایل محیط

nano /opt/marginlift/.env
NODE_ENV=production
APP_ORIGIN=https://marginlift.ir
SESSION_SECRET=<خروجی اول>
POSTGRES_PASSWORD=<خروجی دوم>
ARTIFACT_ENCRYPTION_KEY=<خروجی سوم؛ دقیقاً ۶۴ کاراکتر>
ARTIFACT_KEY_VERSION=v1
TRUST_PROXY=true
MARGINLIFT_LOG_LEVEL=info
CADDY_EMAIL=<ایمیل عملیات>

۴. اجرا

chmod +x ops/vm/deploy.sh ops/vm/backup.sh
./ops/vm/deploy.sh

اسکریپت PostgreSQL را بالا می‌آورد، schema را می‌سازد و JSON فعلی را فقط در دیتابیس خالی مهاجرت می‌کند.

۵. بررسی نهایی

docker compose -f docker-compose.production.yml ps
curl -s https://marginlift.ir/api/health
docker compose -f docker-compose.production.yml logs --tail=100 app

در پاسخ health باید "status":"ok" و "driver":"postgres" دیده شود. سپس در داشبورد، بخش «اعتماد و دسترسی» را باز کنید.

۶. backup روزانه

0 3 * * * /opt/marginlift/ops/vm/backup.sh >> /var/log/marginlift-backup.log 2>&1

volume دیتابیس را بدون backup حذف نکنید. فایل JSON قبلی را تا پایان smoke test نگه دارید.
