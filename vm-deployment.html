VM Deployment

استقرار MarginLift روی VM

این راهنما برای یک VM لینوکسی با Docker، دیسک پایدار و یک instance از اپ نوشته شده است.

معماری

Cloudflare (DNS / SSL / WAF)
        |
        v
VM: Caddy روی ۸۰ و ۴۴۳
        |
        v
Docker app روی ۳۰۰۰، فقط شبکه داخلی
        |
        v
Volume: /opt/marginlift/data/db.json

پورت ۳۰۰۰ نباید عمومی باشد؛ Caddy ورودی عمومی را می‌گیرد و درخواست را به اپ داخل شبکه Docker می‌فرستد.

پیش‌نیازها

  • VM لینوکسی به‌روز با Docker Engine و Docker Compose plugin
  • volume پایدار برای /opt/marginlift/data
  • firewall با پورت‌های ۲۲، ۸۰ و ۴۴۳؛ پورت ۳۰۰۰ بسته
  • ورود SSH با کلید

دریافت پروژه

sudo mkdir -p /opt/marginlift
sudo chown "$USER":"$USER" /opt/marginlift
cd /opt/marginlift
git clone https://github.com/mohammadbayati/Marginlift.git .
cp .env.example .env

اگر repository خصوصی است، از SSH deploy key استفاده کن: git clone git@github.com:mohammadbayati/Marginlift.git .. بعد از clone باید فایل‌های package.json، Dockerfile و docker-compose.production.yml در همین مسیر باشند.

تنظیم `.env`

NODE_ENV=production
APP_ORIGIN=https://marginlift.ir
SESSION_SECRET=<secret تصادفی حداقل ۳۲ کاراکتری>
MARGINLIFT_DB_PATH=/app/data/db.json
CADDY_EMAIL=<ایمیل عملیاتی>
TRUST_PROXY=true

اجرا

chmod +x ops/vm/deploy.sh ops/vm/backup.sh
./ops/vm/deploy.sh

اتصال Cloudflare

رکورد A برای @ را به IP عمومی VM وصل و proxy را روشن کن. سپس www را به دامنه اصلی هدایت کن. SSL/TLS روی Full (strict)، Always Use HTTPS و WAF فعال شود.

backup روزانه

0 3 * * * /opt/marginlift/ops/vm/backup.sh >> /var/log/marginlift-backup.log 2>&1

بررسی نهایی

docker compose -f docker-compose.production.yml ps
